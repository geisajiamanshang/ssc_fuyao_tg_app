# 转正海报和同步信息自动化 v1.0.0

发布日期：2026-09-21
版本标识：regularization-today-v1.0.0
功能完成由用户确认，并授权从 test 合并到 main。

## 功能范围

监听云昭小组工作对接群中的 `转正提醒-恒睿-今日转正` 关键字，命中【恒睿】分区下的
“今日转正:”人员名单后：

- 按花名从当月转正信息 Drive 文件中取出对应的转正海报图片和【转正通知】祝贺语
  （自动去掉祝贺语开头的🆗️等符号），按“部门-小组”字段匹配到对应部门全员群
  （复用入职周年的 `ANNIVERSARY_GROUP_RULES` 路由表，AIGC原创部路由到
  ACFAN特战队全员群）。
- 同时把匹配到的花名对应的【转正信息同步】原文，发送到人事信息同步-SSC3组。

两类消息都先进入 SSC 收藏夹，分别由独立的审批码放行（海报+祝贺=测试4/4，
转正信息同步=测试4.1/4.1），互不干扰；SSC 批准后消息转发到目标群，收藏夹里的
草稿随即自动删除。

## 验证

- 花名/部门/祝贺语解析用 2026 年 9 月真实转正信息导出文件核对过，不是纯合成样例。
- 新增的 handler 单元测试覆盖：正常发送两条草稿、目标群未配置时跳过同步消息、
  找不到部门匹配时只报错不误发、重复消息不会重复处理、SSC 审批后正确删除收藏夹
  草稿（海报和同步信息两条审批码分别验证）。
- 全仓库 98 项测试通过，Python 编译通过。
