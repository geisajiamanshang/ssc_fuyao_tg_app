# Offer 审批自动化监控 v1.0.0

发布日期：2026-09-20
版本标识：offer-monitor-v1.0.0
功能完成由用户确认，并授权从 test 合并到 main。

## 功能范围

- BP Offer 进入 SSC 收藏夹，审批后发送联合管理群。
- 技术中心初审、二审、终审；其他组织初审和终审。
- 当日批量终审、缺失审批提醒、提前终审记录保留及后补审批推进。
- 同一测试账号多角色识别与重复事件去重。
- 招聘简历字段兼容、编码和姓名联合匹配、招聘通知失败重试。
- 招聘私聊生成入职确认、已验证提前私聊恢复及阻塞原因提示。
- 群通知继续通过 SSC 收藏夹审批，测试审批码为测试1。
